# Integration test cases: one batch run per line.
#
#   name | control | accounts | transactions | history | return code
#
# control, accounts, transactions and history are file names under
# testdata/control, testdata/accounts, testdata/transactions and
# testdata/history.  "-" for history means the batch runs without a
# history file.  A file name that does not exist is deliberate: it is
# how the missing-file cases are expressed.
#
# The expected outputs of each case are in testdata/expected/<name>/.
# tests/integration/run-integration.sh explains how they are compared.
